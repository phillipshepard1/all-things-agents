# Deals Pipeline

Visualize and manage your entire sales process with Client Keeper's deals pipeline.

## Pipeline Stages

The default pipeline includes these stages:

1. **New Lead** - Initial contact made
2. **Qualified** - Budget and timeline confirmed
3. **Showing** - Actively viewing properties
4. **Offer Made** - Submitted an offer
5. **Under Contract** - Offer accepted
6. **Closed** - Deal completed

## Managing Deals

### Creating a Deal

1. Click **+ New Deal** from the pipeline view
2. Select or create a client
3. Enter deal details (property, price, etc.)
4. Choose the initial stage
5. Save

### Moving Deals

Drag and drop deals between stages, or click on a deal to update its status manually.

### Deal Details

Each deal tracks:
- Property address
- Expected value
- Commission amount
- Key dates (showing, offer, closing)
- Related documents
- Activity log

## Customizing Your Pipeline

You can customize stages to match your workflow:

1. Go to **Settings > Pipeline**
2. Add, remove, or rename stages
3. Set stage colors and icons
4. Define automation triggers

<Callout type="info">
Changes to pipeline stages apply to all new deals. Existing deals retain their current stage settings.
</Callout>

## Pipeline Analytics

Track your performance with built-in analytics:

- Deals by stage
- Average time in each stage
- Conversion rates
- Monthly/quarterly trends
- Commission projections
