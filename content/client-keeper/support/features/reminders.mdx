# Reminders & Automation

Stay on top of every opportunity with Client Keeper's intelligent reminder system.

## Types of Reminders

### Manual Reminders

Create one-time reminders for specific tasks:
- Follow-up calls
- Send documents
- Schedule meetings
- Check listing status

### Automated Reminders

Set up recurring reminders based on:
- Client birthdays and anniversaries
- Days since last contact
- Contract milestone dates
- Listing expiration dates

## Setting Up Reminders

### Quick Reminder

1. Open any client or deal
2. Click **+ Add Reminder**
3. Choose date and time
4. Add a note
5. Save

### Automation Rules

Create rules that trigger automatically:

```
IF client has not been contacted in 30 days
THEN create reminder to follow up
```

<Callout type="tip">
Start with a "30-day no contact" automation. It's the most valuable reminder rule for maintaining relationships.
</Callout>

## Notification Settings

Choose how you want to be notified:

- **Email** - Daily digest or instant notifications
- **Push** - Mobile app notifications
- **SMS** - Text message alerts (Pro plan)
- **In-app** - Dashboard notifications

## Best Practices

1. **Don't over-remind** - Too many reminders leads to ignoring them
2. **Be specific** - Include context in reminder notes
3. **Review weekly** - Clear completed reminders regularly
4. **Use automation wisely** - Start simple, add complexity over time
