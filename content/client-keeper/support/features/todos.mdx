# How to Create a To-Do in Client Keeper

This guide walks you through the process of creating a new task or reminder in your Client Keeper to-do list. You can set a date, time, and even link the task to a specific contact.

## Requirements

- Client Keeper app installed on your device
- Pre-saved contacts (optional, for task linking)

## Steps

### Step 1: Access the To-Do Section

Navigate to the main screen and locate the navigation bar at the bottom. Tap the checkmark icon to view your to-do list.

### Step 2: Create a New Task

Select the purple plus icon (+) in the top-right corner to open the creation form.

### Step 3: Complete Task Details

Fill in the following information:

| Field | Description |
|-------|-------------|
| **Title** | Enter a clear task name (e.g., "Meet with Client") |
| **Description** | Add optional notes or additional context |
| **Date** | Select from an interactive calendar |
| **Time** | Use the time picker to set hours, minutes, and AM/PM |
| **Repeat** | Choose frequency options like "One Time" or "Every Week" |
| **Contact** | Link the task to a saved contact by selecting from your contact list |

### Step 4: Save

Tap the purple **Create** button to finalize. Your task appears on the "Current" to-do list with its due date and linked contact.

## Troubleshooting

<Callout type="warning">
**Create button inactive?** Verify you've entered required fields, particularly the title and date.
</Callout>

<Callout type="info">
**Missing contacts?** Add contacts through the Contacts section before linking them to tasks.
</Callout>

## Managing Tasks

- Tap any task to edit it
- Select the circle beside its title to mark it complete
- Completed tasks move to the "Completed" tab for reference
