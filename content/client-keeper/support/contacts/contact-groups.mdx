# How to Create and Manage Contact Groups

This guide explains how to organize contacts using groups within the Client Keeper app. You can create new groups, add multiple contacts, and manage group membership.

## Prerequisites

At least one contact must already be saved in the application before creating a group.

## Part 1: Creating a New Group

### Step 1: Access the Groups Tab

From the main Contacts screen, select the **Groups** tab in the top navigation bar. New users will see a "No Groups" message initially.

### Step 2: Initiate Group Creation

Click the purple plus icon (+) in the top right corner. The "Create Group" page will open.

### Step 3: Enter Group Name

Click the "Group Name" field and enter a descriptive name. Examples:
- Warm Leads
- Family
- Past Clients
- Referral Partners
- VIP Clients

### Step 4: Select Contacts

1. Click **Choose Contact** to view your saved contacts list
2. Check the boxes next to each contact you wish to add
3. Purple checkmarks indicate selections
4. Click **Save** when finished selecting

### Step 5: Complete Creation

1. Selected contacts appear as tags on the Create Group page
2. Click the purple **Create** button at the bottom
3. Your new group now appears on the Groups screen

## Part 2: Managing Group Members

### Removing a Contact from a Group

1. **Locate the Contact** - Go to the Contacts tab and select the specific contact
2. **Access Edit Mode** - Click the edit icon (pencil symbol) at the top of the contact's profile
3. **Modify Group Assignment** - Scroll to the "Add To a Group" section and click the 'x' next to the group name
4. **Save Changes** - Click the Save button or checkmark icon to confirm removal

### Adding a Contact to an Existing Group

1. Open the contact's profile
2. Tap the edit icon
3. Scroll to "Add To a Group"
4. Select the group(s) to add them to
5. Save your changes

## Use Cases for Groups

| Group Type | Purpose |
|------------|---------|
| **Hot Leads** | Contacts actively looking to buy/sell |
| **Past Clients** | Previous transactions for referral outreach |
| **Sphere of Influence** | Friends, family, and connections |
| **Referral Partners** | Lenders, inspectors, other agents |
| **Event Attendees** | Open house or networking event contacts |

<Callout type="tip">
Groups work great with the CSV export feature. Export a specific group to create targeted marketing campaigns.
</Callout>
