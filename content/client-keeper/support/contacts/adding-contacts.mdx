# How to Add a New Contact

This guide explains the complete process for adding a new contact to the Client Keeper app, including personal information entry, property details, and follow-up reminder setup.

## Requirements

- Client Keeper app installed on your device
- Contact's name, email, and/or phone number

## Steps

### Step 1: Navigate to Contacts

1. From the main "Follow Up" screen, locate the bottom navigation bar
2. Select the two-person icon to access your contacts list
3. The screen will be empty if this is your first contact

### Step 2: Create New Contact

Tap the purple plus icon (+) in the top-right corner to begin.

### Step 3: Enter Personal Information (Part 1 of 3)

Fill in the client's personal details on the "Create New Contact" page:

| Field | Description |
|-------|-------------|
| Name | First and last name |
| Email | Primary email address |
| Phone | Mobile or work number |
| Address | Home or mailing address |
| Birthday | For birthday reminders |
| Notes | Any additional context |

### Step 4: Add Property Details (Part 2 of 3)

Link properties to the contact on the "Properties" screen:

- Add current home details
- Include properties they're interested in
- Note housiversary dates for follow-up reminders

### Step 5: Set Up Follow-Up Reminders (Part 3 of 3)

Create reminders for future client contact:

1. Choose follow-up frequency
2. Select preferred contact method
3. Add any notes for the reminder

### Step 6: Save and Finalize

Tap **Save and Continue** after setting up follow-ups. Your new contact appears in the contacts list.

## Troubleshooting

<Callout type="warning">
**Plus icon unavailable?** Ensure you've finished entering information in the Email or Phone Number field.
</Callout>

<Callout type="info">
**Need corrections?** Tap the contact's name from your list to edit or delete information.
</Callout>

## Result

Your follow-up reminders will display on the main "Follow Up" screen, helping you maintain consistent client communication.
